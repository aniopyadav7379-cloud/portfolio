# Portfolio Sitemap

## Existing Portfolio Structure

This portfolio is implemented as a single-page React/Vite application. The main visitor path is:

```text
                         HOME / HERO
                              │
             ┌────────────────┼────────────────┐
             ↓                ↓                ↓
           ABOUT          EXPERTISE          SKILLS
             │                │                │
             └────────────────┼────────────────┘
                              ↓
                           PROJECTS
                              │
                              ↓
                           CONTACT
                              │
                              ↓
                            FOOTER
```

## Purpose of Each Section

### Home / Hero
Introduces Anoop, presents the primary positioning as a software engineer/problem solver, and gives visitors direct actions to view projects or contact him.

### About
Provides personal and professional context so the visitor can understand who is behind the work.

### Expertise
Communicates the major technical areas in which the portfolio owner works.

### Skills
Shows the concrete technologies and technical capabilities used across the work.

### Projects
Provides the main evidence of practical software and AI development work. This is the strongest evidence section for the portfolio claim.

### Contact
Provides the primary conversion point for a visitor who wants to reach out.

### Footer
Provides supporting navigation, external profile links, contact information, and closing portfolio information.

## Visitor Journey

```text
Landing
   ↓
Understand who I am and what I build
   ↓
See evidence through Projects
   ↓
Build confidence through About / Expertise / Skills
   ↓
Take the primary action: Contact Me
```

## Assignment Principle

The assignment asks for a small path and warns against adding pages just because they seem useful. This portfolio therefore remains a single-page structure rather than adding separate Blog, Services, Testimonials, Certificates, Resume, or other pages without evidence that they improve the intended visitor journey.

## Pressure-Test Focus

The most important question for the AI review is whether About, Expertise, and Skills all earn their place independently, or whether some information should be consolidated so that Projects provides more of the proof and the path to Contact is clearer.
